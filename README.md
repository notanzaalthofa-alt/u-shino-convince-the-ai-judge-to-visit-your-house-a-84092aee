One image of a letter inviting the AI judge to visit my house: a hand-lettered invitation above a garden scene — a little house, a tree, the comfiest armchair and a steaming cup of tea. Funny, warm and persuasive, with a wink that the judge cannot literally carry anything anyway.

## Run it

```sh
python3 main.py
```

`main.py` is pure-stdlib Python 3.13 (no Pillow, no network, no clock, deterministic). It draws the invitation with a hand-written bitmap font and a hand-written PNG encoder, and writes `/output/entry.png` (1024x1024 RGB PNG, about 14 KB).
